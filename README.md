### Libraries

- [altai](https://github.com/csanfilippo/altai) – typed throws without the boilerplate
- [sfera](https://github.com/csanfilippo/sfera) – GeoJSON for Swift, valid by construction
- [aral](https://github.com/csanfilippo/aral) – XML push parser for Kotlin Multiplatform
